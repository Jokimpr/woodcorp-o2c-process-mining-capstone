# WoodCorp O2C Process Mining Capstone

## Project Overview

This project was developed as part of the Celonis Process Mining Capstone Program.

The objective was to analyze WoodCorp's Order-to-Cash (O2C) process and identify operational bottlenecks affecting on-time delivery performance.

---

## Business Problem

WoodCorp was experiencing significant delivery delays across factories, warehouses, and customer segments.

The goal was to identify root causes and recommend operational improvements to increase delivery reliability.

---

## Tools Used

- Celonis Process Mining
- Process Explorer
- KPI Analysis
- Root Cause Analysis
- Process Optimization

---

## Dataset

- 19,953 Order-to-Cash records
- Multiple factories
- Multiple warehouses
- Customer delivery performance data

---

## Key Findings

### Customer Analysis

- Total Orders: 19,953
- Late Orders: 7,091
- On-Time Delivery: 64.46%
- Late Delivery Rate: 35.54%

High-volume customers contributed disproportionately to late deliveries.

---

### Factory Analysis

- Aachen and Essen generated the highest number of late deliveries.
- Significant performance variation existed between factories.

---

### Warehouse Analysis

- Automated warehouses outperformed non-automated warehouses.
- Capacity balancing opportunities were identified.

---

## Recommendations

1. Prioritize operational improvement initiatives in Aachen and Essen.
2. Expand warehouse automation programs.
3. Reallocate capacity from overloaded facilities.
4. Standardize best practices from top-performing factories.

---

## Business Impact

The proposed improvement roadmap can increase On-Time Delivery performance from 64.46% toward the 80% target benchmark.
